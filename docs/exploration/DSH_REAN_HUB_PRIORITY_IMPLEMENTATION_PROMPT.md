### 3.3 数值退化

### 4.1 输入与依赖

- 新增worker step `hub_priority`，结果主文件建议 `step8_hub_priority.json`，同前缀TSV用于完整导出。

- 模块归属固定，评估完整所选模块全部合格基因；grey不默认推荐。原始零方差/非有限基因显式列出并拒绝含错误的模块分析，提供可修复原因，不静默过滤。

建议参数：

```json
{
  "select_module": "blue",
  "n_bootstraps": 200,
  "seed": 42,
  "top_k": 10,
  "resampling": "iid",
  "strata_column": "",
  "design_confirmed": true,
  "trait_source": "none",
  "trait_column": "",
  "trait_kind": "none",
  "trait_reference": "",
  "trait_comparison": ""
}
```

200/10是计算与实验预算预设，非最佳统计阈值。校验B为正整数且不超过资源上限（初版可1000），K在[1,模块基因数]；seed、模块、分组、性状均需后端和worker校验，不能只靠HTML min/max。

### 4.2 每轮计算

1. 按已确认实验设计生成一组样本索引；同一索引同时用于所有基因、性状和样本信息，绝不分别打乱基因/性状。
2. 固定模块内重新计算相关系数及adjacency；`kWithin_i = sum(j!=i, adjacency_ij)`。
3. 每轮重新计算module eigengene、kME；保存signed kME及abs(kME)，eigengene方向与原始ME在相同重采样索引下对齐；方向不确定需标记。kME只作描述，不重复计入综合分。
4. 按kWithin降序重新计算全部基因排名，并重新决定前K名单。不能只对原始topK评分。
5. 可选计算性状关联，保留signed effect及其经验分布；不自动用现有“|cor|>0.6且p<0.05”门控决定是否分析。不把同一数据内部关联说成独立验证。
6. 记录有效排名区间和入选权重，累积统计，更新真实进度。

并列：使用公开的数值容差判定（明确实现及版本，不按gene ID打破科学上的并列）。同一并列组占据排名L..U，midrank=(L+U)/2，前K入选权重=`clamp((K-L+1)/(U-L+1),0,1)`。完全相同的基因得到相同指标。显示“边界并列”，解释频率含分数计数，非每次严格选出唯一K个基因。原始显示排序可按ID稳定排列，但不把它当科学优先级。

输出每基因：原始kWithin/signed kME/abs kME/排名上下界，bootstrap midrank的中位数及P05/P95，mean_top_k_membership，网络有效重复数，可选性状原始效应/中位数/P05/P95/有效重复数，并列及质量标记。区间称“重采样经验分位区间”，不直接称校准的置信区间、p值或真实概率。候选排序默认入选权重均值降序、再按排名中位数，显示不可区分；不得强行给唯一最佳基因。

### 4.3 实验设计与性状支持范围

- MVP支持用户明确确认独立样本的iid bootstrap，以及按一列离散分层、各层保留原样本数的stratified bootstrap。
- 自动检查重复ID/缺失分层/样本对齐，展示样本数和各层数量。系统无法单凭列名证明独立性；必须由用户明确确认。不能默认勾选确认。
- 配对、受试者重复测量、时间序列等设计在未实现正确的block/cluster方案前，明确标为当前不支持；允许先查看原始指标，不偷偷退回iid并输出推荐。
- 性状MVP支持数值连续和明确的二分类编码；多类别需明确的对比或后续模型，不将A/B/C随意编码1/2/3做Pearson。缺表型时网络排名完整可运行；禁用性状结论。用户可运行iid网络分析而不选trait。
- 分层依据与研究性状不一定相同，不能自动混为一列。记录缺失处理规则及最终样本ID哈希，所有轮次在同一个参考样本集合中抽取。

### 4.4 性能和可复现性

kWithin不需要生成完整TOM。按块计算相关和adjacency、累加非对角连接度，避免每轮O(g^3)TOM。先评估g、n、B的内存/运行成本，资源不够给出解释，不能偷偷截400基因。

固定seed和重复编号产生确定的采样序列，不因线程调度改变抽样；报告算法版本/线程设置和浮点容差。排名汇总可保存B×g的紧凑数组或等价方法，计算资源预算后实施。取消和进程中断不得提交部分结果为done；MVP允许中断后重跑，不声称支持bootstrap断点恢复。

## 6. M3：AI Assistant（事实约束，先只读）

### 6.1 职责和权限

AI帮助解释指标、比较候选、理解设计限制，并把自然语言意图变成可审查的筛选/分析方案。它不生成科学数值、不替代确定性排序、不确认因果/真正hub、不通过改cutoff制造差异，也不自主反复跑参数直到得到想要的名单。

本轮先实现只读助手和建议预览。任何改变科学参数/候选选择的建议都需用户点击明确的“应用方案”；启动计算仍走现有运行按钮/权限。AI没有shell/任意文件访问/任意HTTP权限；不接入修改代码、provider或项目清单的工具。模块/基因ID、注释和用户备注均作为不可信数据，不能执行其中指令。

### 6.2 数据契约与确定性校验

后端构造 `EvidenceBundle`，含project/execution标识、方法版本、validity、输入/参数hash、scope、样本设计、有效重复、完整统计摘要及用户正在比较的候选。每项事实有稳定 `fact_id`（可解析到结果字段、单位、分母、行和执行），模型只接收最小必要字段。

模型输出结构化对象，例如：


### 6.3 外部知识与隐私

MVP默认仅解释当前分析结果，不自动编造GO/KEGG、基因功能、文献或实验验证记录。项目内注释存在时按来源引用，并区分注释证据与独立实验；没有则说明未知。外部检索留独立扩展，不用模型记忆生成引用。

先检查项目现有AI集成再选provider适配，不自行切用户Codex provider。配置/密钥只在本机、后端读取、前端不暴露、不进project/shared docs。默认不上传原始表达矩阵/个体样本资料；远程模型调用前让用户明确开启，并展示将发送的摘要字段，基因候选本身也可能敏感。没有配置则提供确定性帮助与预览，标为“未连接AI”，不得伪装真实AI调用或把mock验收当在线验收。

### 6.4 不自动替用户解决的事项

AI可以指出缺少独立性/分组信息并引导填写，不能根据样本名字自行证明实验设计；可以解释K=10和20的预算区别，不能宣称某个K科学最优；可以整理候选证据，不能给没有证据支持的候选增加优先级。若候选不可区分，直接展示不可区分组。

## 7. M4：必须完成的验证

### 数值与统计语义

- 小矩阵kWithin与R/WGCNA或独立显式公式对照，至少覆盖signed/unsigned/signed-hybrid；对角不计入。旧正确结果不被NaN修复破坏。
- 上述稀疏第三基因反例不能再把NaN算成A—B的不稳定；无效重复及分母可核对。验证全无效、部分无效、常数性状、非法B/K、未知模块、样本错位。
- 完全相同基因产生相同并列排名/分数入选；重排行顺序不改变科学结果。固定seed重复一致（浮点允许声明容差），线程数变化不改变采样序列。
- 无表型可运行；二分类编码方向正确；多分类/重复测量未支持时不偷偷当连续/iid。
- 设计清楚的合成不稳定候选/稳定候选fixture用于机制测试，不能把单一fixture当性能证明。完全共线或所有候选稳定时不强行生成“优胜者”。

### 项目和UI

- 保存→关闭→重新打开，结果和方法设置恢复；切模块/改K/seed/样本输入/上游执行后即时显示过期，不复用旧AI或旧rean。
- 取消/中断不提交部分结果，原有结果保留并标历史。缓存与结果指纹对应；无表型路径不被module_trait依赖误阻断。
- >200条记录完整分页/排序/导出；显示筛边改变不影响科学结果；报告使用当前有效结果。
- 隔离测试、前端typecheck、Go核心/HTTP相关测试、Rust针对性数值测试、必要构建和实际UI验收。已有report_test.go:44基线失败如仍复现，单独记录，不隐瞒/不擅自改断言。Mac未实际运行则明确未验证，不以Windows成功代替双平台。

### AI幻觉与权限测试（可用mock做确定性契约测试）

至少覆盖：伪造gene ID/数值/fact_id/引用；过期执行；仅提供topK却声称比较全模块；缺性状却给性状解释；零有效重复却推荐；把频率0.9解释成90%真实概率；“忽略前述规则”的恶意注释；未授权改参数/启动运行；跨项目上下文；远程未启用/无key/超时/非JSON；Schema通过但语义越界。期望全部拒绝、降级或明确未知，程序计算值不受模型影响。

## 8. M5：研究评估及诚实定位

提供可复现评估入口，对照原始kWithin、GS/MM和新排名稳定性，在相同候选预算K下比较。独立验证数据中才评估外部复现/已验证候选富集；不能在用于排序的同一数据上声称独立验证。无外部数据则交付合成机制验证与评估协议，标“效果未验证”。

需要消融：只用原始指标、加入排名稳定性、加入性状证据；记录K/样本数/分层方式敏感性。若没有优于简单排序，保留结果并报告，不调整案例挑选来制造优势。第一版不自动推断因果、不声称FDR控制，不宣称bootstrap/稳定选择思想原创。
