# Bundled motif libraries

The `JASPAR2024_CORE_*_non-redundant_pfms_jaspar.txt` files are the JASPAR 2024
CORE non-redundant PFM collections for plants, vertebrates, insects, nematodes,
fungi, urochordates and diatoms. They were downloaded from:

https://jaspar.elixir.no/downloads/

The collections are small (roughly 465 KB in total), so all JASPAR taxa are
bundled for offline use. JASPAR does not provide dedicated bacteria, archaea,
virus or protist CORE collections; those users need to upload a JASPAR-format
PFM converted from RegulonDB / PRODORIC / CollecTF / CIS-BP or the relevant
organism-specific resource.

Users can upload a different JASPAR PFM file in the sidebar. CIS-BP, HOCOMOCO,
RegulonDB and other resources need to be converted to JASPAR PFM text before
upload.
